STUDY NOTE
==========
실행:
- index.html을 브라우저에서 열면 사용할 수 있습니다.
- GitHub 저장소에 index.html을 업로드하고 Vercel에서 해당 저장소를 Import하면 배포할 수 있습니다.
- 별도 빌드 명령이나 환경변수는 필요하지 않습니다.

중요:
- 현재 버전은 IndexedDB를 사용해 자료를 현재 브라우저/기기에 저장합니다.
- 로그인 및 클라우드 동기화는 포함하지 않았습니다. 따라서 기기마다 자료가 따로 저장됩니다.
- 상단 '백업' 버튼으로 JSON 파일을 내려받고, 다른 기기에서 '복구'로 가져올 수 있습니다.
- 브라우저 데이터 삭제 전 반드시 백업하세요.
- 업로드 파일은 파일당 12MB 이하로 제한됩니다.
